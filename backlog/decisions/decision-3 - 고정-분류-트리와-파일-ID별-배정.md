## Context

사용자는 `ledger/도서목록.md`의 현재 분류 트리를 유지하고, Google Drive 폴더 구조와 독립적으로 강제하기를 요청했다.
고정 분류표와 파일 ID별 배정표, 등록된 분류만 선택하는 검증, 미분류 검토 및 엄격 모드 적용에 동의했다.

## Decision

- 현재 16개 분야·55개 세부분야의 이름과 순서를 `config/categories.yaml`로 이관한다. 목록 순서를 출력 순서로 사용하고 각 노드에 고정 ID를 부여한다.
- `config/book_categories.yaml`은 Drive 파일 ID를 세부분야 ID에 연결한다. 제목은 관리용 설명이다. 제목·폴더명이나 AI 추정으로 자동 배정하지 않는다.
- 트리 구조·이름·ID·순서는 명시적 변경 요청 없이 바꾸지 않는다. 새 책은 기존 세부분야 중 하나에만 배정한다.
- 존재하지 않는 세부분야, 대분야 직접 배정, 중복 노드·파일 ID·YAML 키는 오류로 처리한다.
- 미등록 파일은 정식 트리 밖의 검토 대기로 표시한다. 엄격 모드는 검토 대기 도서가 하나라도 있으면 출력 파일을 교체하지 않는다.
- 빈 분야와 세부분야도 렌더링하며 설정 순서를 유지한다. 향후 전체 대장 생성에서도 동일한 분류기와 쓰기 전 검증을 사용한다.

## Consequences

- 폴더를 옮기거나 파일명을 바꿔도 Drive 파일 ID가 같으면 분류가 유지된다.
- 같은 제목이어도 파일 ID가 다르면 별도 배정이 필요하다. 파일 재업로드·복사로 ID가 바뀌는 경우도 검토 대상이다.
- 전체 대장과 변경 이력의 자동 갱신은 KBI-6에서 연결하며, 현재는 로컬 스냅샷으로 분류 검토 보고서를 생성한다.
